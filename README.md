# Simple Interest Calculator

A simple calculator program written in Python that calculates simple interest based on principal amount, annual rate of interest, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$

Where:
* **P** = Principal amount
* **T** = Time period (in years)
* **R** = Annual interest rate# github-final-project
